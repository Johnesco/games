1D automaton. Each row is one generation, scrolling downward.

3 states: Off → On → Dying → Off
Off turns On if exactly 2 On neighbors.

4 states: Empty, Electron head, Electron tail, Conductor
Conductor becomes Head if 1-2 Head neighbors. Click to cycle states.

Each cell advances to the next state if enough neighbors already have it.
